## 一、任务概述

桌面 App（desktop/，Electron 壳 + PyInstaller 后端）实施三项能力：
1. 无边框标题栏（`titleBarStyle:'hidden'`，红黄绿保留）
2. 关闭询问自绘 modal（退出 / 后台托管 / 取消 + 记住选择）
3. Tray 后台托管（菜单栏图标 + 缩小动画 + 进程常驻）

前置条件：前端视觉优化任务已提交（git log 971 系列已合并），可动前端文件。

## 七、补充修复

- **window-state 防写坏**：缩小动画中 `resize` 事件会触发 `saveWindowState`，把缩小尺寸存进下次启动 → 加 `isAnimatingToTray` flag 跳过。
- **记忆检查时机修正**：`close-choice-init` 应在点红点时（`desktopShowCloseChoice`）检查记忆而非应用启动时（否则启动即退出/托管）。已在 store.js 修正。
