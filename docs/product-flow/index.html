四、路径规则（AI 必读）

所有写工具接受的路径规则。禁止路径穿越、绝对路径和非 Markdown 文件。

路径规则速查
禁止 原因
..路径穿越
/ 开头绝对路径
非 .md 结尾只支持 Markdown
projects / archive系统目录
不存在的项目目录先用 nav__list_dir 列出
正确示例：
common-knowledge/术语表.md
projects/首页重构/common-knowledge/改版方案.md
projects/MyKnowledge 项目知识管理平台/projects/前端设计与开发
archive/首页重构

七、异常处理

常见错误及其恢复方法。

锁被占用
错误：写锁不存在 → 调 maint__acquire_lock
错误：LOCK BUSY → 其他 AI 正在操作，稍后重试
路径错误
路径不存在 → 调 nav__list_dir 列出现有项目
路径格式错误 → 参考第四节正确格式
路径穿越禁止 → 使用 KB 相对路径
写操作失败
文档已存在 → 用 write__update_document 替代 write__create_document
无写锁 → 先调 maint__acquire_lock
git 冲突 → 调 maint__read_diff 查看差异，确认后重试
