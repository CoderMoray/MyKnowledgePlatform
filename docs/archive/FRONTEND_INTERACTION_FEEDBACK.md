## A. 入口 & 登录

### A1. Setup 页样式
- **问题**：首次登录的 setup 页是否沿用 Raycast 毛玻璃风格全屏居中弹窗？
- **你的决定**：沿用 Raycast 毛玻璃风格全屏居中弹窗就好，因为首次进入时这是默认主题，所以我们没必要为每个主题都做设计。

### A2. 服务离线处理（12 场景全覆盖）

**统一定义**：所有离线提示统一用「服务已断开」，不用「网络已断开」。

**分级响应**：

| # | 场景 | 策略 |
|:-:|------|------|
| 1 | 编辑器内打字 | 顶部横幅「服务已断开，编辑将保存至本地」+ IndexedDB 写入 |
| 2 | 浏览仪表盘/列表 | 顶部横幅，已缓存数据照常展示 |
| 3 | 浏览文档页（只读） | 顶部横幅，已加载内容照常看 |
| 4 | 导航到新页面 | 全屏阻断弹窗「服务连接已断开，请检查服务后重试」+「重试连接」按钮 |
| 5a | 冷启动离线 + 无草稿 | 全屏阻断弹窗 |
| 5b | 冷启动离线 + 有 IndexedDB 草稿 | 不阻断，直接进编辑恢复模式 + 横幅「服务已断开，显示的是本地草稿」 |
| 6 | 点击操作按钮（新建/删除/保存） | toast 提示 + 3 秒消失。文案：服务已断开，创建/删除未执行 |
| 7 | 网络恢复 | 横幅消失 + IndexedDB 草稿自动同步 + 0.36s 淡出 |
| 8 | 浏览器前进/后退 | 有缓存→同场景 2/3；无缓存→同场景 4 |
| 9 | Setup 页 | 已设置过身份→skip；未设置→阻断弹窗「首次设置需要服务连接」 |
| 10 | 状态页 | store 有缓存→展示+横幅；无→阻断 |
| 11 | 关闭标签页 | beforeunload → 触发 IndexedDB 写入 → 释放编辑锁。不弹确认窗 |
| 12 | 后台静默失败（SSE/锁轮询） | SSE 断开→5s 静默重连，3 次失败→header 小黄点「实时更新已断开」；锁轮询→静默吞掉，下次自动重试 |

## B. 仪表盘

### B1. 仪表盘布局
- **问题**：仪表盘是「指标卡片行 + 最近更新列表」两段式，还是保持当前简单的项目卡片网格？
- **你的决定**：[待实现] 三区布局：
  - **公共知识**（非根目录时显示为「项目知识」）：来自 `common-knowledge/`，文档卡片。字段：名称 + 摘要 + 日期 + 作者。
  - **项目**（非根目录时显示为「子项目」）：来自 `projects/`，项目卡片。字段：名称 + 摘要（读 readme.md frontmatter）+ 最近更新日期 + 文档数。**注意：readme.md frontmatter 无 author 字段，不展示作者。**
  - **已归档**：来自 `archive/`，同项目卡片 + status badge（已完成/已取消/已废弃），空时隐藏此分区。
  - 每个分区空时显示灰色提示文字（「暂无文档」「暂无子项目」「暂无归档」）。
  - 所有文件后缀（.md）不在前端显示。文件中文命名映射后续单独设计。

### B2. 点击项目卡片
- **交互**：hover 展开平滑面板（300ms delay），三区分组（知识/子项目/归档），可滚动。点文档→#doc，点子项目→#project，无嵌套。面板泄露 150ms 收起。子项目无标签（均为 active），归档保留状态 badge。
- **补充（已确认）**：doc-card__meta 显示 '-' 是因为 API 返回的字段（name/path/is_dir/modified）与卡片模板期望的字段（updated_at/summary/doc_count）不匹配。需在三区重构时一并修复。

### B3. 最近更新交互
- **问题**：最近更新条目的时间显示格式（相对时间"3天前" vs 绝对日期"7月23日"）？
- **你的决定**：7 天及以内显示为相对时间，7 天以上显示为绝对日期（yyyy-mm-dd）。

## D. 文档页（已合并 #doc/{path}）

### D1. Ref 引用浮层
- **问题**：ref: 链接点击后浮层显示什么内容？a) 只显示标题+摘要+路径  b) 显示完整的引用文档 Markdown 渲染  c) 显示摘要+前 200 字预览
- **你的决定**：[已确认，待实现] **A + C 结合**。默认显示 A（标题+摘要+路径+作者日期+「打开文档」链接）。hover 后展开为 C（摘要 + 前 200 字预览 + 总字数 + 打开链接）。轻量扫一眼 → 不点不跳，hover 即预览。

### D2. 文档操作
- **问题**：删除按钮放在 header 还是底部？
- **你的决定**：[已确认，待实现] 放在 **header 右侧**。布局：面包屑（左）··· 编辑按钮（左）删除按钮（右）。
  - **编辑按钮**：默认透明蓝字 → hover 蓝底蓝字突出。
  - **删除按钮**：默认浅橙框+浅橙字（弱化）→ hover 红底白字（醒目警示）。
  - **锁定态**：编辑/删除按钮隐藏，header 右侧显示红色「只读」标签代替。
  - **正常态**（KB 未锁）：显示「编辑」「删除」按钮，无标签。
  - **编辑中**：header 右侧显示绿色「编辑中」标签，「编辑」按钮切换为「保存」。删除按钮隐藏。
  - **编辑点击**：直接进入编辑模式（TipTap 聚焦）。
  - **删除点击**：弹出确认弹窗。红边框 + 文档名 + 不可撤销提示 + 取消/确定红色按钮。
- **补充场景——编辑锁（待实现）**：
  - 用户打开文档编辑中 → 切到 AI client → AI 尝试修改同一文档 → 后端检测到活跃编辑锁 → 拒绝并返回：「文档 `xxx` 正被编辑中，请前往 [链接] 完成或放弃编辑后重试。」
  - 需要后端新增 `/api/edit-lock/{path}` 的 acquire / release / heartbeat 端点。
  - 锁超时 10 分钟无心跳自动释放。
  - 浏览器崩溃/关标签页 → 结合 E3 本地临时存储兜底。

### E3. 自动保存
- **问题**：是否需要自动保存功能？间隔多久？
- **你的决定**：[部分已确认]
  - **触发策略**：每次停止输入 1s 后自动保存（debounce），飞书式即时保存，无保存按钮。
  - **header 状态**：编辑中显示绿色「编辑中」标签，原「编辑」按钮切换为「保存」（手动保存 + 重置离线兜底）。Ctrl+S/Cmd+S 等同保存。
  - **关页面/切路由**：`beforeunload` + 路由守卫触发一次保存 + 释放编辑锁。
  - **后端离线时**：save API 失败 → 写入 IndexedDB（`myk-drafts` store）。后端恢复后检测到草稿 → header 横幅「你有未同步的编辑内容，是否立即同步？[立即同步] [忽略]」。
  - **不影响版本管理**：每次保存调 `PUT /api/document/{path}`，后端自动 git commit（`update: 文档名 by 用户名`），独立 commit 不丢历史。
  - **草稿存储结构**（IndexedDB）：DB `MyKnowledgeDrafts`，Store `drafts`，Key = 文档 path，Value = `{ content, title, summary, savedAt, docVersion }`。
  - **历史版本回退**：[已确认] 版本列表 + diff 预览 + 「恢复此版本」→ 二次确认 → 取旧文存新 commit。不需要 blame（本地 git author 全是自己）。逐行作者归属（blame 视图）留待 SaaS 化时再做。

## 待解决问题

### 刷新时闪黑（浏览器级，前端无法控制）
- **现象**：系统暗色模式下，刷新页面（亮色主题）时出现一帧黑色闪烁
- **已尝试**：
  1. `<meta name="color-scheme">` 改为 `only light` — 无效
  2. `<html>` 标签 inline `style="background:#fafafa"` — 无效
  3. head 同步 script 设置 `document.documentElement.style.colorScheme` — 无效
  4. 纯 HTML splash（不依赖 Alpine/JS，body 第一字节即渲染）— 无效
- **结论**：闪黑发生在 HTML 到达浏览器之前（HTTP 请求阶段的标签页默认背景），前端代码无法控制。未来研究 Service Worker 缓存方案。

### 刷新时出现一帧旧页面
- **现象**：刷新页面时，旧页面内容闪现一帧后才出现加载动画
- **已尝试**：`Cache-Control/Pragma/Expires` meta 标签禁用缓存 — 无效
- **推测**：Chrome 内存缓存或 bfcache 导致，需研究 `pageshow.persisted` 事件强制重载
